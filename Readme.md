# HR Analytics Dashboard

## About the Project

This project is an HR Analytics Dashboard built using Excel, SQL Server, and Power BI. The goal was to analyze employee data and create an interactive dashboard that helps understand employee performance, salaries, overtime, training, and departmental trends.

The project starts with cleaning the raw dataset in Power Query, followed by SQL analysis to calculate business KPIs, and finally presents the insights through an interactive Power BI dashboard.

---

## Dataset

- **Dataset:** Employee Performance & Productivity Data
- **Source:** https://www.kaggle.com/datasets/mexwell/employee-performance-and-productivity-data
- **Records:** 100,000 Employees

---

## Tools Used

- Microsoft Excel
- Power Query
- SQL Server (SSMS)
- Power BI
- DAX

---

## Data Preparation

Before building the dashboard, the dataset was cleaned in Power Query.

The cleaning process included:

- Removing duplicate records
- Checking data types
- Renaming columns
- Removing unnecessary columns
- Handling inconsistent values
- Preparing the data for analysis

---

## SQL Analysis

SQL Server was used to analyze the cleaned dataset and generate business insights.

Some of the SQL concepts used in this project include:

- Aggregate Functions
- GROUP BY
- ORDER BY
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- KPI Queries

Some KPIs calculated include:

- Total Employees
- Average Monthly Salary
- Average Performance Score
- High Performer Employees
- Department-wise Employee Count

---

## Power BI Dashboard

This project contains **6 interactive dashboard pages**, allowing users to explore HR data from different perspectives.

The dashboard includes:

- Executive Overview
- Employee Profile
- Department Analysis
- Salary Analysis
- Performance Analysis
- Overtime & Training Analysis

Features used in Power BI:

- KPI Cards
- Slicers
- Bar Charts
- Line Charts
- Donut Charts
- Tables
- DAX Measures
- Cross Filtering
